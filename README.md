# PravataLab

This repository contains the Nexus Research Lab website.

## Local Development

You can run and test the website locally using Docker.

### Prerequisites

- [Docker Desktop](https://www.docker.com/products/docker-desktop/) installed and running.

### Running Locally

1. Start the server using the helper script:
   ```bash
   ./start.sh
   ```
2. Open [http://localhost:4000](http://localhost:4000) in your browser.
3. Editing any file (e.g. `index.html` or `style.css`) will automatically rebuild the site and reload the page in your browser.
